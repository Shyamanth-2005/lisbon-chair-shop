# Lisbon Chair Shop

Welcome to the Lisbon Chair Shop - a beautiful, responsive online furniture store showcasing premium chairs.

## 🪑 About

This project is a modern, elegant chair shop website featuring a curated collection of high-quality chairs. The design focuses on clean aesthetics and user-friendly browsing to showcase our beautiful furniture collection.

## 🚀 Features

- Responsive design that works on all devices
- Elegant, minimalist aesthetic
- High-quality chair imagery
- Customer testimonials section
- Easy navigation

## 📁 Project Structure

